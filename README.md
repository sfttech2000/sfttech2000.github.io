# sfttech2000 CYD projects

https://sfttech2000.github.io/ : games and tools for the ESP32-2432S028R "Cheap Yellow Display",
each with a web installer (Chrome / Edge, or Android Chrome with an OTG cable).

To add a project: one line in the PROJECTS list in index.html and a 640x480 cover in img/.
The version and the install count come from each installer (its manifest and its Abacus counter).
